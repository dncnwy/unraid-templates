# Spoolroom Unraid templates

This repo publishes the Unraid Community Apps template, not the watcher implementation.
See [README.md](README.md) for user setup and [the template](templates/spoolroom-watcher.xml)
for the published configuration. Keep setup codes, tokens, and user-specific data out of Git.

## Before resuming work

- Verify the actual worktree, branch and HEAD, status and diff. Reconcile the linked issue or
  rollout tracker with the current PR and checks for that commit before editing or saying work remains.
- Treat chat, auto memory, and local handoffs as leads. A merged template does not prove it is
  visible in Community Apps; check publication separately or say it is unverified.
- Reopen completed work only with evidence of regression or an unmet requirement. At a meaningful
  checkpoint, update the existing issue, PR or plan with the commit, evidence, and next action or
  blocker. Keep unmerged worktree details local; do not create a second tracker.
